## 勘误与范围说明

| 页码 | 原课件中的问题或易误读处 | 笔记处理 |
| --- | --- | --- |
| 5–7 | 推力交替记作 f 和 u，末质量写成 m(t) | 统一记号；指标是 m(t_f)，并补充干质量和可行性解释。 |
| 8–10 | 已称 α 为相对加速度，方程却写成带点的 α；平面题采用三维模长记号 | 按定义和量纲恢复 α；平面内令第三分量为零。 |
| 14 | 将性能指标和价值函数混称 | 区分给定控制的代价与优化后的价值。 |
| 39、44、47 | 变分存在条件、向量内积记号，以及把驻值写作与极值等价 | 区分泛函存在和可微；补内积转置；驻值是必要条件。 |
| 53–54、57 | 垂直靶线用“无穷斜率”；已知第一积分常数后仍写正负两根 | 用终时变化为零直接推导；保留与常数相同的斜率符号。 |
| 58 | 标量二次指标引入例未给完整边界 | 按原式推导通解；附加边界只用于明确标注的示范。 |
| 63–66 | 分部积分符号错，横截条件的两端记号容易误读 | 积分内协态导数项取正；固定端点不额外规定协态。 |
| 77 | 只列固定终时的端点条件 | 单列终时自由时需要增加的条件。 |
| 84 | 由谱判定存在及至多 n−1 次切换未列齐前提 | 分开可达性和最优存在；补能控性与实谱等前提，双积分直接算仿射开关函数。 |
| 97、101、103 | 一般燃料问题、LTI 小节、双积分例的终时条件不同 | 明确标记自由、固定、自由，避免混用唯一性与存在性。 |
| 102、116 | 最少燃料小节内误写“最短时间” | 按小节标题与绝对值代价判断为最少燃料。 |
| 105 | 只列阈值处幅值严格在 0 与 1 之间的示意 | 逐点极小的允许集包括两端；是否真为最优还需满足整条轨迹。 |
| 109、112、117 | 把燃料指标称作能量；“响应时间最短”的比较范围容易误读 | 明确是归一化燃料；滑行再刹车只在相同最少燃料的方案中最快。 |
| 114–118 | 区域 R1 图中纵坐标符号、近似最省的表头和结尾措辞 | 纵坐标为 −ε/2；只有下确界，ε 方案有限可行。末句“最少时间”应为“最少燃料”。 |
