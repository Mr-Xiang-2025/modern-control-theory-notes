## 勘误与范围说明

| 页码 | 原课件的问题或易误读处 | 笔记处理 |
| --- | --- | --- |
| 3 | 提纲列出多输入极点配置，正文未单列完整方法或题目 | 保留其位置提示，另列有限范围的补充方法。 |
| 10 | 将闭环输入矩阵误称为输出反馈矩阵 | 区分输出增益 H 与反馈后的输入矩阵。 |
| 15 | 能控矩阵写成首项 A | 首项改为输入列 b，按原矩阵算得满秩。 |
| 21 | 将内部极零对消可能破坏的性质写成能控性 | 状态反馈保持能控性；可能丧失能观测性，E01 有反例。 |
| 22 | 多项式和增益公式中系数下标次序不一致 | 统一按升幂定义，增益差从常数项开始。 |
| 23 | 认为单输入列有多个非零分量会使系数方程出现未知量高次项 | 秩一行列式恒等式保证方程对反馈增益为仿射；H01 手算验证。 |
| 24、27 | 题面为 +2，解答改用 −2；第 27 页二次系数方程的右端还误写为 1 | 保留两种题意，分别求增益与核验稳定性；二次系数正确为 4。 |
| 25 | 由传递函数无显式对消就断言系统能控 | 直接验证课件选定的规范型；任意隐藏的状态实现须另外判断。 |
| 42 | 标题写成消除理想传感器特性 | 实际目的是补偿传感器的非理想动态。 |
| 43–44、48 | 模型漂移和频段优缺点是工程说明 | 说明初值、未知输入、频带、模型和传感器的前提。 |
| 56–61 | 容易混同对象端扰动、测量噪声和补偿器输出 | 写出三个独立通道，并核对抵消所需的注入位置、增益与稳定性。 |
| 67–68 | 理想图和估计图的回授信号及前置增益不同 | 分别推导电流内环等效关系；注明标度与估计误差假设。 |
